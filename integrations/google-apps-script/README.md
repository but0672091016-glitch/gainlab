# Форматовані email-сповіщення GainLab

Стандартне email-сповіщення Netlify Forms дозволяє змінити тему, але не HTML-шаблон тіла листа. Цей обробник призначений для безкоштовного проміжного рішення через Google Apps Script і Gmail:

1. Netlify Forms приймає та зберігає перевірену заявку `gainlab-order`.
2. Netlify надсилає підтверджену заявку на приватну адресу Google Apps Script через Outgoing webhook.
3. Скрипт перевіряє секрет, перетворює заявку на український HTML-лист із таблицями та надсилає його через Gmail власника.

## Секрети

У репозиторії немає адреси отримувача або webhook-секрету. Їх потрібно зберегти в **Project Settings → Script Properties**:

- `GAINLAB_RECIPIENT` — адреса отримувача повідомлень;
- `GAINLAB_WEBHOOK_SECRET` — довгий випадковий секрет.

## Підключення

1. Створити проєкт на `script.google.com` у Google-акаунті власника.
2. Скопіювати `Code.gs` у редактор Apps Script.
3. Додати обидві Script Properties.
4. Розгорнути як Web app: виконувати від імені власника, доступ — `Anyone`.
5. До отриманої URL вебзастосунку додати `?token=<GAINLAB_WEBHOOK_SECRET>`.
6. У Netlify відкрити **Forms → Submission notifications → Add notification → Outgoing webhook**, вибрати форму `gainlab-order` і вставити URL.
7. Надіслати контрольне тестове замовлення та підтвердити отримання форматованого листа.
8. Лише після успішного тесту вимкнути старе стандартне email-сповіщення Netlify, щоб листи не дублювалися.

## Безпека

- Скрипт обробляє тільки форму `gainlab-order`.
- HTML-значення екрануються перед додаванням до листа.
- Webhook захищений секретом, який не зберігається у Git.
- Ідентифікатор заявки кешується на шість годин для захисту від повторної доставки одного листа.
- У журналі не записуються контактні дані або склад замовлення.
