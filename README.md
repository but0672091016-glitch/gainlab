# GainLab

Локальная демонстрационная версия украинского интернет-магазина спортивных товаров. Реализованы главная страница, спортивный новостной дайджест, каталог с категориями и вложенными разделами, страницы товаров, общая корзина и тестовое оформление. Каталог умеет загружаться из PostgreSQL через локальный `DATABASE_URL` или Netlify `NETLIFY_DB_URL`, а без доступной базы безопасно использует демонстрационные данные из кода.

Все товары, цены, скидки и остатки в интерфейсе являются тестовыми и не представляют реальное предложение магазина.

## Что уже можно посмотреть

- адаптивную главную страницу в фирменной чёрно-зелёной гамме;
- оригинальный логотип GainLab;
- мобильное меню и поиск по тестовым товарам;
- вкладки товарных подборок;
- рабочие демо-действия корзины и избранного;
- категории, рекламные блоки, преимущества и футер;
- раскрывающееся меню каталога с категориями и разделами;
- каталог из 32 тестовых товаров с поиском, фильтрацией и сортировкой;
- серверный дайджест новостей силовых видов спорта;
- страницы-заготовки юридической информации.

Серверные заказы, авторизация, межустройственная корзина, постоянное избранное и админ-панель относятся к следующим этапам и пока не реализованы.

## Что установить на Windows

Для просмотра интерфейса без базы данных достаточно:

1. [Node.js](https://nodejs.org/) 20.9 или новее (рекомендуется Node.js 24 LTS).
2. pnpm 11.25.0 через Corepack:

```powershell
corepack enable
corepack prepare pnpm@11.25.0 --activate
```

Для работы локальной базы дополнительно нужен [Docker Desktop](https://www.docker.com/products/docker-desktop/).

Покупать домен или хостинг для разработки не нужно.

Публичная тестовая версия размещена бесплатно на Netlify: [magical-belekoy-ed4358.netlify.app](https://magical-belekoy-ed4358.netlify.app). Исходный код хранится в [GitHub-репозитории](https://github.com/but0672091016-glitch/gainlab). Параметры развёртывания и сравнение с Cloudflare Pages описаны в [`DEPLOYMENT.md`](DEPLOYMENT.md).

## Быстрый просмотр только интерфейса

Откройте PowerShell в папке проекта и выполните:

```powershell
pnpm install
pnpm dev
```

Откройте в Chrome или Edge `http://localhost:3000`. Изменения в коде автоматически появляются в браузере после сохранения файлов.

## Полный локальный запуск с PostgreSQL

```powershell
Copy-Item .env.example .env
pnpm install
pnpm db:generate
pnpm db:up
pnpm exec prisma migrate deploy
pnpm db:seed
pnpm dev
```

## Просмотр базы данных

После запуска PostgreSQL:

```powershell
pnpm db:studio
```

Команда выведет локальный адрес интерфейса для просмотра таблиц и тестовых данных.

## Просмотр с телефона без хостинга

Телефон и компьютер должны быть подключены к одной Wi-Fi сети.

```powershell
pnpm dev:network
ipconfig
```

Найдите IPv4-адрес компьютера и откройте на телефоне `http://ВАШ_IP:3000`. При первом запуске Windows может попросить разрешить доступ через брандмауэр для частной сети.


Полная последовательность: `pnpm check`.

## Основные команды

| Команда | Назначение |
| --- | --- |
| `pnpm dev` | Локальная разработка на `localhost:3000` |
| `pnpm dev:network` | Просмотр с других устройств в локальной сети |
| `pnpm build` | Production-сборка |
| `pnpm start` | Запуск production-сборки |
| `pnpm db:up` | Запуск PostgreSQL через Docker Compose |
| `pnpm db:down` | Остановка PostgreSQL |
| `pnpm db:generate` | Генерация Prisma Client |
| `pnpm db:migrate --name <имя>` | Создание и применение миграции |
| `pnpm db:seed` | Заполнение тестовыми данными |
| `pnpm db:studio` | Визуальный просмотр базы |

## Структура

- `app/` — маршруты Next.js и глобальные стили.
- `components/` — интерактивные компоненты интерфейса.
- `lib/` — единый загрузчик каталога, преобразование записей базы, тестовые данные и общие типы.
- `prisma/` — схема базы, начальная миграция и seed-скрипт для всех 32 тестовых товаров.
- `netlify/database/migrations/` — автоматические миграции управляемой тестовой базы Netlify.
- `public/brand/` — предоставленный логотип.
- `docs/reference/` — предоставленный визуальный референс.
- `tests/` — автоматические проверки данных интерфейса.
- `docker-compose.yml` — локальный PostgreSQL.
- `netlify.toml` — безопасные параметры тестовой сборки на Netlify.
- `DEPLOYMENT.md` — инструкция и ограничения тестового размещения.
- `AGENTS.md` и `PROGRESS.md` — постоянный контекст разработки.

## Ограничения текущей проверки

Docker CLI в текущем окружении не обнаружен. Поэтому схема Prisma валидируется, преобразование записей базы покрыто тестами и проект собирается, но фактический запуск PostgreSQL, миграция и seed должны быть дополнительно проверены в окружении с Docker или управляемой базой.
